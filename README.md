# 슬터디

로봇 **슬**과 함께 영어·일본어·중국어·스페인어·체스를 조금씩 배우는 웹앱이에요.
서버는 내 컴퓨터에서 돌아가요 (개인 서버). 다른 프로그램 설치 없이 **Node.js**만 있으면 돼요.

## 실행하기

1. `start.bat`을 **더블클릭**하세요.
2. 검은 창에 "슬터디 서버가 켜졌어요!"가 뜨고, 브라우저가 `http://localhost:5173` 으로 열려요.
3. 검은 창을 닫으면 서버가 꺼져요. 쓰는 동안은 켜 두세요.

## 폰에서 들어가기

- 폰과 컴퓨터가 **같은 와이파이**에 있어야 해요.
- 검은 창에 나온 `같은 와이파이의 폰: http://192.168.x.x:5173` 주소를 폰 브라우저에 입력하세요.
- 안 열리면 Windows 방화벽 창이 떴을 때 **허용**을 눌렀는지 확인하세요.

## 가입 코드

- 가입할 때 **가입 코드**가 있어야 해요. 처음 켜면 `config.json`에 코드가 하나 만들어지고, 검은 창에도 보여요.
- 바꾸려면 `config.json`의 `inviteCodes`를 고치세요. 여러 개도 돼요: `"inviteCodes": ["SEUL-1234", "FAMILY"]`
- 코드 없이 둘러보는 **체험하기**를 끄려면 `"allowGuest": false`.

## AI 키 넣기

AI가 새 레슨을 만들어요. 키는 `config.json`에만 저장되고 화면(브라우저)으로는 절대 나가지 않아요.

```json
"geminiKeys": ["AQ.첫번째키", "AQ.두번째키"],
"grokKeys": ["xai-키"],
"grokModel": "grok-4-fast"
```

- **Gemini 무료 키**는 https://aistudio.google.com/apikey 에서 받아요. 여러 개 넣으면 돌아가며 쓰고, 한도가 차면 다음 키로 넘어가요.
- Gemini가 다 안 되면 **Grok**(xAI)으로 넘어가요. `grokModel` 이름은 xAI 콘솔(https://console.x.ai)에서 지금 쓸 수 있는 모델 이름을 확인해서 넣으세요.
- 고친 뒤에는 서버를 껐다 켜세요. (가입 코드는 바로 적용돼요)
- **키가 없으면** 앱에 들어 있는 레슨만 돼요: 영어·일본어 첫 두 단원, 중국어·스페인어 첫 단원, 체스 전체.

## 전체 화면

- 앱 위쪽의 **전체 화면** 버튼을 누르세요.
- 폰에서는 브라우저 메뉴의 **"홈 화면에 추가"**를 하면 앱처럼 전체 화면으로 열려요.

## 기록

- 가입한 사람, XP, 연속 학습일은 `data/db.json`에 저장돼요.
- AI가 만든 레슨은 `data/lessons/`에 저장해 두고 다시 써요 (AI 한도 아끼기).
- `data/` 폴더를 지우면 기록이 모두 사라져요. 백업하려면 이 폴더를 복사하세요.

## 개발용 검사

```
node tools/check.mjs      # 체스 퍼즐·레슨 검사
node tools/api-test.mjs   # 서버 시험 (진짜 기록은 안 건드림)
```
